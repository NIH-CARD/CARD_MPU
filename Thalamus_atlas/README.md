## What's in this repo

Each repository contains a link to the pipeline of interest (below). Pipelines are split between repos to maintain independence of method.

| | Analysis | Tools |
|---|---|---|
| 📡 | **Cell-cell communication** — ligand-receptor interaction analysis across cell types | CellChat |
| 📊 | **Differential cell-type proportion** — Calculation of transformed cell-type proportions and diffential cell-type proportion analysis | Propeller |
| 🌋 | **Pseudobulked differential gene expression** — aggregated per-sample, per-cell type DEG | RUVseq, DEseq2|
|  🚧| **STMN2 cryptic exon detection** — TDP43-related cryptic exon analysis | Regtools & LeafCutter |
| 🧠 | **Spatial transcriptomics** — spatially resolved gene expression profiles | Visium & Seurat |
